# Prerequisites

Allow 25 minutes. You need to read Gateway listeners, HTTPRoute parent
references, path and header matches, and ReferenceGrant permissions. You
need `kubectl get`, `kubectl apply`, `kubectl edit` and `kubectl exec`.

The terminal has `kubectl` and the lab's Kubernetes context. The `shuttle`
pod has `curl`. No local Helm installation or controller setup is needed.
The Gateway API objects use the addon's v1.6.1 experimental definitions.
